# Portfólio pessoal

Este repositório reúne meu portfólio pessoal, desenvolvido como atividade da disciplina Fundamentos da Programação Web.

O site apresenta informações sobre minha formação, projetos e formas de contato, além de uma breve apresentação profissional.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegação entre as seções do portfólio
- Layout responsivo para diferentes tamanhos de tela
- Alternância entre tema claro e escuro
- Formulário de contato com validação dos campos
